mania-sr-pp-reimagined

This repository is the algorithm repository of the Reimagined osu!mania pp algorithm, and this page renders the dataset that the engine publishes. The four-algorithm comparison below is a by-product of validating that algorithm against the ones it competes with — it is not what the repository is for, and it is not a ranking of osu!mania players.

Rankings

Every player in data/index.json. Totals are weighted sums over that algorithm's own ordering of the player's scores (0.95n); the move column is the player's rank under that algorithm against the same player's Bancho rank.

Search syntax

Free text matches artist, title, difficulty, mapper and the mod string; everything is case-insensitive and several terms are ANDed. A field form is field<operator>value with =, ==, :, !=, <, >, <=, >= — the same shape as osu!'s beatmap search. Quote a value with spaces: title:"eternal white".
